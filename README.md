A short, quiet text for a reader who has carried many voices today. It thanks that reader for one specific act — not hurrying past this one — and rests in one small, warm image: a cup cooling beside an open book, made by someone already back at work.

## Run it

```bash
python3 main.py
```

This writes the entry text to `/output/entry.txt`.
